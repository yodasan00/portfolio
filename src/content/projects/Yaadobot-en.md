**Yaadobot** is a high-performance, real-time WhatsApp multi-agent bot powered by modern LLMs, persistent state management, and an interactive admin dashboard.

- Integrated **Baileys WebSocket client** with LLM APIs for natural conversational capabilities, contextual memory, and automated workflows.
- Built interactive gamification systems, custom media converters, and user utility plugins.
- Containerized the application using **Docker** and deployed on **AWS EC2** with automated process management via **PM2** and robust error recovery.
- Implemented secure API authentication and dashboard monitoring for bot health and usage metrics.
