A research-grade **Hybrid NLP Model** combining rule-based morphological methods, BiLSTM-CRF sequence tagging, and biaffine dependency parsing for the **Gurung language**.

- Built a hybrid NLP pipeline combining rule-based morphological rules with deep learning sequence taggers (**BiLSTM-CRF**).
- Implemented **biaffine dependency parsing** to extract syntactic relationships and parse trees from Gurung sentences.
- Created a curated, annotated corpus for the Gurung language with morphological and syntactic tag sets.
- Built a **FastAPI** backend and an interactive **Angular** web interface for real-time sentence parsing, tree visualization, and POS tagging (achieving **83% POS accuracy** and **91% LAS**).
